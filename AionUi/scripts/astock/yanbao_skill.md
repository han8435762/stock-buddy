## 数字处理与单位换算规范（**强制执行**）

### 核心问题：千万级/亿级数字换算必须精准

**禁止出现的错误示范：**

- ❌ 35,107万股 → 错误换算成 35.107亿股
- ✅ 35,107万股 = 35,107 × 10,000股 = 351,070,000股 = **3.5107亿股**
- ❌ 852,802,345元 → 错误换算成 85.28亿元
- ✅ 852,802,345元 = 8.52802345亿元 ≈ **8.53亿元**

### 标准换算规则（**写入时必须遵守**）

**第一步：先去千位分隔符，再换算**

```
带逗号的数字：先去除逗号 → 35,107 → 35107
然后乘以单位 → 35107 × 10000股 = 351070000股
最后换算成目标单位 → 351070000 ÷ 100000000 = 3.5107亿股
```

**第二步：使用【零位法】核对小数点位置**

| 单位层级 | 对应零的个数 | 示例        |
| -------- | ------------ | ----------- |
| 个       | 0            | 1           |
| 十       | 1            | 10          |
| 百       | 2            | 100         |
| 千       | 3            | 1,000       |
| 万       | 4            | 10,000      |
| 十万     | 5            | 100,000     |
| 百万     | 6            | 1,000,000   |
| 千万     | 7            | 10,000,000  |
| 亿       | 8            | 100,000,000 |

**换算口诀：**

- 万 → 亿：**除以10000，小数点左移4位**
  - 例：35107万股 ÷ 10000 = 3.5107亿股 ✅
- 元 → 亿元：**除以100000000，小数点左移8位**
  - 例：852802345元 ÷ 100000000 = 8.528亿元 ✅
- 元 → 万元：**除以10000，小数点左移4位**

### 数字格式化规则

1. **原始数据保留**：所有从 `02_转换资料`、`a-stock-data` 或 WebSearch 获取的原始数字，先在草稿区完整记录（带逗号、带单位和来源）
2. **去逗号处理**：计算前必须先去除所有千位分隔符
3. **精确计算**：所有计算都要有中间过程，中间计算过程保留4位小数，最终结果保留2位小数
4. **反向验证**：换算完成后，反向计算验证
   - 3.5107亿股 × 10000 = 35107万股 ✔ 验证通过
   - 8.53亿元 × 100000000 = 853000000元 ≈ 852802345元 ✔ 误差在可接受范围

### 常见易错场景（**必须核对**）

| 场景      | 易错点      | 正确做法                           |
| --------- | ----------- | ---------------------------------- |
| 股本/市值 | 万股→亿股   | 左移4位，35107万 = 3.5107亿        |
| 营收/利润 | 元→亿元     | 左移8位，852802345元 = 8.53亿元    |
| 市盈率    | 市值÷净利润 | 两者单位必须统一（都用亿或都用万） |
| 市销率    | 市值÷营收   | 两者单位必须统一                   |
| 每股指标  | 元/股       | 分子分母单位层级一致               |

## 阶段一：研究准备（启动时立即执行）

### 1.1 公司识别

用户可能给出公司全名、简称或股票代码，首先确认：

1. **公司全名**（A股上市公司名称）
2. **股票代码**（6位数字，如600988）
3. **所属交易所**（沪市/深市/北交所）
4. **主营业务一句话描述**（什么原料→什么产品→卖给谁）
5. **所在产业链名称**（如：镁产业链、锂电产业链、光伏产业链、半导体产业链等）
6. **获取当前时间** 需要使用最新的信息

**注意：所有数据必须使用最新时间点的数据 不能使用过期数据**

> 使用 `a-stock-data` skill 获取公司基本信息（F10数据）。如获取失败，用 websearch的skill或者工具 搜索"{公司名} 主营业务 简介 股票代码"。

### 1.2 确定研报定位

根据公司主营业务判断研报类型，采用对应分析重点：

| 公司类型      | 判断特征                        | 分析重点                         |
| ------------- | ------------------------------- | -------------------------------- |
| 周期资源型    | 主营大宗商品（金属/化工/能源）  | 商品价格周期、成本曲线、产能扩张 |
| 制造成长型    | 主营中间品/零部件，下游新兴领域 | 市占率、产能释放、客户渗透       |
| 消费品型      | 直接面向C端或B端分散客户        | 品牌力、渠道、ROE质量            |
| 科技硬件型    | 主营芯片/设备/材料，技术壁垒高  | 技术迭代、国产替代进度           |
| 互联网/软件型 | 轻资产，网络效应                | 用户规模、ARPU、利润率弹性       |

## 阶段二：数据收集（系统性、并行获取）

### 2.1 财务数据（严格按来源优先级获取）

获取财务报表和财务指标时必须依次使用以下来源，只有前一来源缺失、时间范围不足或无法确认时，才能降级到下一来源：

1. **优先读取 `02_转换资料`**：使用当前公司目录中由 PDF 一一转换得到的年报、半年报、季报 Markdown。优先最新报告，并按报告期补齐近 5 年数据；不要直接读取对应 PDF。
2. **其次使用 `a-stock-data` skill**：仅补充转换资料缺失的年份、字段、实时行情、估值和机构预测，并记录接口来源与获取日期。
3. **最后使用 WebSearch**：仅当转换资料和 `a-stock-data` 均无法满足时搜索补充；优先公司官网、交易所和监管披露，不得用搜索摘要代替原文。

下方“基础行情”属于实时市场数据，仍优先用 `a-stock-data` 获取；财务三表、核心财务指标、股权与分红等财务数据严格按上述三级优先级获取。

**基础行情**

- 当前股价、总市值、流通市值
- 52周最高/最低价
- 动态PE、静态PE、PB、PS

**财务三表（近5年年报 + 最新季报）**

- 利润表：营业收入、毛利润、营业利润、归母净利润、综合毛利率、净利率
- 资产负债表：总资产、净资产、资产负债率、流动比率、速动比率
- 现金流量表：经营/投资/筹资活动现金净流量

**核心财务指标**

- ROE（加权）、ROA、ROIC
- 应收账款余额及占营收比
- 存货余额及存货周转天数
- 资本开支（近5年）
- 自由现金流（FCF = 经营现金流 - 资本开支）

**股权与分红**

- 十大流通股东（近4季度变化）
- 近5年分红总额及分红率
- 历次再融资（增发/配股）金额

**机构预测**

- 2-3家券商的2025-2027年EPS预测
- 机构目标价区间

### 2.2 行业与产业链数据（通过 a-stock-data + websearch的skill或者工具 获取）

**行业规模**：用 websearch的skill或者工具 搜索"{行业名称} 市场规模 2025 2026 增速 产量"

**产业链上游**：搜索"{上游原料名称} 价格走势 2024 2025 2026 主要供应商"

**产业链中游**（公司所在位置）：搜索"{公司名} 产能 市占率 竞争对手"

**产业链下游**：搜索"{下游应用领域} 需求增速 新能源 轻量化"

**竞争对手财务**：若当前资料库中有对应公司的年报、半年报或季报 Markdown，优先从 `02_转换资料` 获取；其次用 `a-stock-data` 获取关键财务指标；最后使用 WebSearch 查找官方财报补充

**近期公告**：通过 a-stock-data 获取公司近3个月重要公告（产能规划、订单、业绩预告等）

**近期研报**：通过 a-stock-data 的研报功能搜索"{公司名} 研报 深度报告"，参考但不照抄

**近期新闻**：通过 a-stock-data 获取近30日重要新闻，识别催化剂事件

## 阶段二·五：数据交叉验证（**强制执行，写报告前必做**）

> **数据交叉验证的落地动作。** 财务数据先以 `02_转换资料` 中的年报、半年报、季报 Markdown 为基准，再用 `a-stock-data` 核对或补缺；只有两者均缺失、无法确认或出现冲突时，才使用 WebSearch 查找公司官网、交易所或监管披露原文。第三方测算（尤其乐观的成长性数字）更常注水。**在进入阶段三分析之前，必须按此优先级对关键数据做一轮交叉验证。** 未经验证的数据不得直接写入报告结论。

### 2.5.1 必须验证的高优先级数据（逐项过一遍）

| 数据类别                                 | 为什么要验                                         | 核验路径或查询示例                                                      |
| ---------------------------------------- | -------------------------------------------------- | ---------------------------------------------------------------------- |
| **核心财务数（营收/归母净利/EPS）**      | 报表与接口口径（合并/母公司、扣非/未扣非）易混     | 先核对 `02_转换资料` 对应财报，再用 `a-stock-data`；仍存疑才搜索官方原文 |
| **参股/子公司盈利与投资收益**            | 权益法收益、分红款常被混淆，是利润主支柱时尤其关键 | `"{参股公司} {年份} 净利润"`、`"{公司} 收到 {参股公司} 分红款 多少亿"` |
| **产能/产量数字**                        | 设计产能 vs 实际产量、新旧扩产口径不一             | `"{公司} {产品} 产能 万吨 {年份}"`（以最新年报/官网为准）              |
| **成长性测算（新业务利润弹性、目标价）** | 卖方/自媒体最容易夸大的环节                        | `"{新业务} 产能 净利润 测算"`，独立反推是否合理                        |
| **行业供需关键数字（产量/需求/缺口）**   | 预测值常被当成既成事实                             | `"{行业} {年份} 产量 需求 同比"`（区分"实际"与"预测"）                 |
| **持股比例/实控人/股本**                 | 不同穿透层级口径不同                               | `"{公司} {参股公司} 持股比例"`、`"{公司} 实际控制人 总股本"`           |

### 2.5.2 验证方法（三招）

1. **多源交叉**：同一数字至少在 **2 个独立来源**（官方公告/年报 + 一个第三方）出现才采信；只有单一自媒体来源的数字标注"待核实"。
2. **勾稽反推**：用已确认的硬数据反推存疑数据，检验是否自洽。
   - 例：`参股公司净利 × 持股比例 ≈ 上市公司投资收益`？反推出的净利与第三方说法差异过大时，以勾稽结果为准。
   - 例：`目标市值 ÷ 预测净利 = 隐含PE`，是否在合理区间？
3. **识别注水**：对"利润暴增""第二增长曲线"类乐观数字，用产能上限做天花板测算（`产能 × 单价 = 营收上限`，再估净利率），明显突破物理上限的一律下修并标注。

### 2.5.3 冲突处理与记录

- **数据冲突时的采信顺序**：公司最新年报/公告 > 交易所/监管披露 > 一致预期/券商研报 > 财经媒体 > 自媒体测算。
- **每个被验证的关键数据**，在草稿区记录：`原始值（来源）→ 验证值（来源）→ 采信值 + 理由`。
- 验证后仍无法确认的，报告中标注"**数据存疑，以公司公告为准**"，**绝不取乐观值充数**。
- 验证中发现的口径差异（如扣非/未扣非、合并/母公司），在报告对应位置用脚注或括号说明。

> **输出要求**：在报告末尾附一个简短的「关键数据核对区」表格，列出做过交叉验证的核心数字及其来源，体现研究的严谨性（参考样板研报的"数字换算核对区"）。

## 阶段三：研究分析框架

### 模块一：行业分析

**1.1 行业底层逻辑**

从"产业链底层"向上还原：

- 产业链全图：原料→生产→中间品→终端，每环节输入物、工艺、产出物
- 成本构成：拆解单位产品完全成本各项占比（%），标出"成本波动核心变量"
- 定价模式：每个环节是市场定价/成本加成/长协定价/项目制，谁掌握定价权
- 利润分配："微笑曲线"还是"倒微笑曲线"，利润集中在哪个环节，原因是什么
- 价格传导：上游成本变化如何逐层传导，每层时滞（周/月/季度）和衰减幅度
- 替代威胁：面临哪些替代材料/技术，当前经济性如何，替代拐点预测

**1.2 生命周期与全球格局**

- 生命周期：萌芽/成长初/成长中/成长后/成熟/衰退，判断依据（产能利用率、需求增速、龙头集中度、投资回报率趋势）
- 中国全球地位：产量/产能/技术分别占全球多少，"大而不强"还是"强而不大"，在全球价值链处于哪个层级
- 领先者经验：哪些国家在高端制造/绿色工艺/前沿技术上领先，具体路径
- 追赶者威胁：哪些国家/企业在快速追赶，时间表与经济性门槛

**1.3 供需格局与价格周期**

- 历史供需表（近5年）：产能、产量、产能利用率、消费量、供需差
- 未来预测（5年）：供给端扩产节奏、需求端增速分领域拆分、供需缺口走势
- 库存周期判断：主动补库/被动补库/主动去库/被动去库，库存绝对水平
- 价格周期复盘：过去3-4个完整周期的驱动因素（需求冲击/供给冲击/政策冲击），价格高低点
- 当前价格位置：相对完全成本的位置，向下空间与向上弹性

**1.4 价格修复驱动因素**（周期型公司必写，成长型公司可简化）

列出当前影响价格的5-7个因素，按强度排序成表，区分：

- 必要条件（成本支撑/替代逻辑）已具备几个
- 充分条件（需求爆发/供给收缩）还缺什么
- 关键验证窗口期（几月份是关键节点）

**1.5 政策与技术环境**

- 监管体系：主管部委、行业协会、标准组织
- 近2年核心政策（国家级）：政策名称、发布主体、核心内容、对行业实质影响
- 地方政策：主要产业集群（省/市）的扶持/管控
- 技术路径：当前主流工艺→下一代路线→颠覆性技术，时间表与门槛
- 碳/能耗约束：是否纳入"两高"管理，相关能耗标准，对成本和门槛的影响

**1.6 国际贸易与出口**

- 出口量、出口额、同比变化，主要品类结构，出口均价趋势
- 主要出口目的地及其需求特征
- 贸易壁垒：反倾销税率、配额、技术标准
- CBAM或类似碳边境机制：时间表、对成本影响测算（如适用）

### 模块二：公司深度分析

**2.1 公司概况与发展历程**

- 基本信息：成立/上市时间、交易所、实际控制人（自然人/国企/外资）
- 发展阶段划分：按关键事件分为3-4个阶段，每阶段核心策略和成果
- 控股链条：最终实控人→各层级持股比例→上市公司（表格展示）
- 管理层：实控人/董事长/CEO背景，历史决策风格评估，是否有创始人文化

**2.2 业务结构与商业模式**

各业务板块收入/毛利率拆解表（格式如下）：

| 板块 | 核心产品 | 营收（亿元） | 占比 | 毛利率 | 同比变化 |
| ---- | -------- | ------------ | ---- | ------ | -------- |

每个核心板块详述：

- 原料采购方式（外购/自供/长协/现货）及成本结构
- 客户结构（大客户集中度，认证壁垒，是否有核心大客户依赖风险）
- 定价机制（成本加成/长协/市场价/项目制）
- 核心竞争壁垒来源（资源/规模/技术/客户关系/品牌/地理位置）

**2.3 产能、产量与产销**

- 现有产能：各基地名称、产品类型、设计产能、当前利用率
- 在建/规划产能：项目名称、规模、预计投产时间、对应资本开支

历史产能利用率对比（表格，近5年 vs 行业平均）：

| 年份 | 产能 | 产量 | 利用率 | 行业均值 |
| ---- | ---- | ---- | ------ | -------- |

- 产能释放节奏与需求匹配度分析
- 融资与分红历史：历次融资额、历年分红额、募资/分红比（>3倍需警惕"圈钱"）

**2.4 财务与业绩归因**

核心财务数据表（近5年）：

| 年份 | 营收 | 同比 | 归母净利润 | 同比 | 毛利率 | 净利率 | ROE |
| ---- | ---- | ---- | ---------- | ---- | ------ | ------ | --- |

深度分析：

- **量价拆解**：营收变化中，量增/量减/价涨/价跌各贡献多少百分点
- **利润归因**：将净利润变化分解为量增效应、价格效应、成本效应、费用效应、结构效应
- **杜邦分析**：ROE = 净利率 × 资产周转率 × 权益乘数，5年趋势，找出拖累ROE的核心因子
- **现金流质量**：经营现金流/净利润比值，判断是否"造血能力强"，投资现金流与扩张节奏
- **应收账款预警**：应收/净利润比值（>5倍高度警惕），账龄结构变化
- **异常信号排查**：会计政策变更、大额减值、关联交易异常、存货异动

**2.5 竞争格局与护城河**

竞争对手全维度对比表（至少3-4家对手）：

| 维度       | 本公司 | 对手A | 对手B | 对手C |
| ---------- | ------ | ----- | ----- | ----- |
| 市值       |        |       |       |       |
| 营收规模   |        |       |       |       |
| 综合毛利率 |        |       |       |       |
| 核心壁垒   |        |       |       |       |
| 市占率     |        |       |       |       |

护城河评估（各维度0-5星，并给出评分理由）：

- 资源护城河：矿产/牌照/稀缺原料控制（★★★☆☆）
- 规模护城河：产能/市占率/成本曲线位置（★★★☆☆）
- 技术护城河：核心专利/工艺秘诀/研发积累（★★☆☆☆）
- 客户护城河：认证壁垒/切换成本/大客户粘性（★★★★☆）
- 品牌护城河：溢价能力/海外认知度（★★☆☆☆）

最后给出：**"如果只能选一个护城河维度，选哪个，为什么"**

**2.6 公司治理**

- 十大流通股东近4季变化：谁在加仓，谁在减仓，机构整体方向，**注意：需要列全，不能只列一部分，并且需要有持股数、百分比、变动方向等有用信息，并且注意当前时间，季报/半年报/年报 哪个时间点离当前时间最近 用哪个**
- 股东人数趋势：筹码集中还是分散（散户化则风险较高）
- 管理层增减持：近1年明细，释放什么信号
- 股权激励：是否有方案、解锁条件、目标业绩，是否足够激进

**2.7 未来增长驱动力**

- 在建产能释放节奏：各项目投产时间表、爬坡周期、满产后利润贡献测算
- 产品结构升级：高附加值/深加工占比提升路径，毛利率修复空间（当前 vs 行业天花板）
- 新赛道布局：在AI/机器人/新能源/低空经济等方向的布局，订单/合作处于哪个阶段
- 机构预测汇总：2-3家券商2025-2027年EPS预测、对应CAGR、目标价
