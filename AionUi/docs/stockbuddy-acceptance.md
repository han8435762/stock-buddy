## 手动验收指引

在 `AionUi/` 目录运行 `bun dev`，逐条验证：

1. **添加公司**：侧边栏"我的公司"→"＋ 添加公司"→搜索"宁德"→多选→"添加公司并获取资料"→自动进入更新中心，任务在后台运行；我的公司出现新卡片。
2. **建库闭环**：更新中心看到任务进度（发现→下载→快照→转换→质检→索引），03\_接口数据产生财务快照。
3. **新建研究**：侧边栏"＋ 新建公司研究"→选公司→输入问题→创建研究→进入会话页，右侧显示"研究上下文 + 引用资料"面板。
4. **指定资料 + Skill**：新建研究选"指定资料"多选 + 选 Skill，或从研究 Skills 页"选择公司并运行"。
5. **最近研究**：侧边栏最近研究按公司分组，点击历史主题进入原会话，底部继续追问。
6. **定时计划**：更新中心"定时计划"新建计划（公司 + 频率）→ 立即运行。
7. **设置**：主导航"设置"→存储管理显示资料根目录。
