## B. 各章节最低内容

### 核心摘要

用3-6段或要点同时回答：行业阶段与周期位置、全球/国内格局、利润池和定价权、公司竞争力和最大增长点、最重要财务排雷项、当前估值与三情景目标区间、投资判断及其失效条件。红灯风险不得藏在正文。

对重资产、多业务或技术制造公司，摘要同时写明一句话核心经营引擎、唯一关键变量，以及核心现金牛/配套业务/修复业务/第二增长曲线/远期期权的主次排序。

### 1.1 产业链、利润池与竞争格局

- 原料 → 工艺 → 中间品 → 制品 → 终端的产业链图谱；每环节说明输入、产出、代表企业和公司位置。
- 单位完全成本拆分，指出最大波动变量；信息不足时用区间并披露来源。
- 市场定价/挂牌价/长协/成本加成/项目制等定价机制和价格传导时滞。
- 利润池分布、议价权、集中度CR3/CR5、进入壁垒、替代技术与经济性拐点。

### 1.2 生命周期、全球格局与供需

- 以需求增速、产能利用率、集中度、资本回报和新增投资判断生命周期。
- 中国在全球产能、产量、技术和价值链中的位置；领先者路径与追赶者威胁。
- 表：近5年历史 + 未来3-5年产能、产量/需求、利用率、供需差，实际值与预测值分栏。
- 供给项目清单、投产/退出概率和爬坡期；下游需求按应用拆分。
- 库存四阶段判断与依据；历史价格周期复盘和当前价格相对成本线/历史分位的位置。
- 若能取得数据，补充行业规模、产值/销量、过去与未来增速；说明规模口径，避免把产量、销售额与可服务市场混为一谈。
- 周期公司增加“价格修复驱动因素”表：排序、因素、强度、必要/充分条件、状态、验证窗口。

### 1.3 成本、定价、传导与价格周期

拆出单位经济模型：售价、原料、能源、折旧、加工、运输、税费与单吨利润；解释原料变化能否传导、时滞及衰减。至少设计一个成本或产品价格变动场景，供估值敏感性使用。

### 1.4 政策、技术、贸易与ESG

- 主管部门、近2年国家及关键地方政策、标准/能耗/安全许可。
- 主流、下一代和颠覆性技术路线及商业化门槛。
- 出口量额、均价、目的地、反倾销/关税/配额/技术壁垒与转口可行性。
- 碳、能耗、水、安全生产、环保支出和治理风险；ESG不能只有口号，需落到成本、产能许可或停产概率。

### 2.1 公司概况、发展阶段与控制链

列成立/上市/注册地/实控人/股本，按3-4个关键阶段复盘战略，展示最终实控人到上市公司的持股链。评价董事长/CEO背景、资本配置和决策风格，用事实支撑。

补充关键历史阶段的“约束—决策—代价—能力沉淀”，并用研发组织、项目兑现、资本回报和管理层稳定性验证企业文化或执行力。引用股东大会、电话会或投资者关系信息时，分开标注管理层原话、已验证事实、管理层目标和研究者推断。

### 2.2 业务结构与商业模式

表：板块、产品、收入、占比、毛利率、同比；同时提供地区结构。逐板块分析采购、自供率、客户集中度、认证/切换成本、定价机制、盈利模式和壁垒。明确现金牛、拖累项、第二曲线和期权业务，避免只写“多元化”。

多法人、多基地公司补充 `法人—基地—产品—产能—收入—利润—资本开支—债务` 映射，说明内部交易和合并抵销。技术业务补充实验室、中试、送样、客户导入、小批量、批量出货和多基地复制的产业化阶段。

### 2.3 产能、产量、产销与资本开支

- 表：基地/产品、设计/有效产能、产量、销量、产销率、利用率、行业均值。
- 表：在建/规划项目、投资额、已投入、预计投产、爬坡、满产收入/利润、资金来源、延期风险。
- 分析产能释放与需求匹配、转固和折旧压力、融资与近5年分红、募资/分红比、高分红与FCF是否错配。
- 重资产公司按项目建立 `资本开支→在建工程→转固→折旧→爬坡→销量→毛利→OCF/FCF` 队列，区分维持性、扩张性、效率型和战略期权资本开支；区分机械完工、试车、商业运行、达产和盈利拐点。
- 计算吨均收入、吨均毛利、吨均折旧、折旧费用率、固定资产周转率和增量资本回报，估算盈亏平衡所需销量/利用率。

### 2.4 财务分析

必须拆成四小节并执行 `financial-analysis.md`。至少展示近5年加最新期核心业绩表、利润表趋势、资产负债表趋势、现金流趋势、关键财务比率趋势。数据允许压缩，但正文不得省略异常解释。

### 2.5 财务与治理排雷

必须执行 `risk-screening.md`，至少展示：红黄绿总表、关键比率多年趋势、审计信息趋势。重大红黄灯逐项解释“事实—阈值/同行—可能机制—反证—结论—跟踪”。

### 2.6 竞争格局与护城河

- 至少3-4家可比对象；全球业务优先加入全球同业，估值可比另选A股可比。
- 表：市值、收入、利润率、ROE、产能/份额、成本位置、研发、估值和核心差异。
- 对资源、规模、技术、客户、品牌/渠道分别0-5星评分并说明证据；最后只能选一个最核心护城河，并写其衰减条件。

### 2.7 公司治理与股东结构

- 最近一期十大流通股东完整10名：持股数、占流通比、较上期变动数量与方向。
- 近4季股东结构、机构/北向/社保等方向；股东户数与户均持股。
- 实控人、董监高近1-3年增减持、质押、离职、处罚；股权激励目标和兑现难度。
- 关联交易、再融资、分红与资本配置纪律。

### 2.8 增长驱动与未来三年预测

- 分项目说明投产、爬坡、销量、价格、毛利率和利润贡献，不能只列故事。
- 表：未来3年分部/分板块销量、价格、收入、毛利率和利润；给出公司合计营收、归母净利、EPS和FCF。
- 表：机构预测，至少2家、优先3-5家，列日期/评级/未来3年EPS或净利/目标价；说明中位数、离群值与分歧来源。
- 新业务补充技术/设备/客户/渠道能否复用、客户导入、设备转产、海外运营与原料保障；管理层远期愿景只作为期权，并反推实现愿景所需的产能、客户、资本开支和ROIC。

### 3.1 估值快照与历史分位

表：股价、市值、股本、52周高低、PE(TTM/静态/前向)、PB、PS、EV/EBITDA、股息率及日期。给出5年和可得的10年PE/PB分位；解释周期底部“PE看似高”的盈利底幻象。

### 3.2 多方法估值、三情景与敏感性

执行 `valuation-scenarios.md`。方法、假设和单位必须可复算。给乐观/中性/悲观目标价区间、概率可选、上行与下行空间、核心变量敏感性和极端压力测试。

### 3.3 分区间操作策略

表：价格区间、对应市值、对应盈利与估值、建议、成立条件。明确当前价所在区间。区间必须来自前述估值和情景，不能主观画线。

在公司或估值章节汇总近5年每股分红、分红总额、分红率和股息率，并列历次重大再融资金额。分析分红是否由FCF覆盖，以及股东总回报来自盈利、估值还是派息。

### 3.4 风险、反证与失效条件

表：风险、触发条件/量化阈值、影响路径、影响程度、先行指标、应对。覆盖商品/价格、供给、需求、客户、政策、技术、贸易/汇率、资本开支/杠杆、治理、环保安全及第二曲线。把最强反证写入正文。

### 3.5 催化剂时间轴

表：具体日期或1/3/6/12个月窗口、事件、确定性、预期弹性、是否已计价、验证方式。只有有证据的事件才能称为催化剂。

### 结论与跟踪指标

分别写行业、公司、投资判断。跟踪指标按周/月/季分组，列数据源、阈值和“触发后如何修正模型”，至少覆盖产品/原料价差、开工与库存、核心下游、产能进度、分部毛利率、资本开支/FCF、杠杆、股东与公告。

重资产或周期公司另附“观察—验证—修正”表，并判断当前处于估值修复、盈利驱动还是景气与预期共振阶段；至少用8个季度的分部销量、价差/吨均收入、毛利率、核心经营利润、库存、资本开支和有息负债验证边际变化。

### 关键数据核对区与资料来源

表：指标、原始值/单位、来源A、来源B、采信值、口径说明、截至日。另列实际与预测的边界、股本与币种口径、缺失项及其结论影响。资料来源按公司公告、监管/政府、行业、行情、券商/媒体分类。

## C. 公司类型适配

| 类型 | 必须强化 |
|---|---|
| 周期资源/化工 | 成本曲线、库存周期、价差、供需平衡、正常化盈利、商品价格敏感性 |
| 制造成长 | 客户认证、份额、良率、产能爬坡、订单转收入、固定成本摊薄 |
| 消费 | 同店/销量/客单、渠道库存、品牌投入、复购、现金转换周期 |
| 科技硬件 | 技术代际、研发资本化、良率、客户导入、国产替代、库存跌价 |
| 软件/互联网 | ARR/用户/ARPU、留存、获客成本、递延/合同负债、现金跑道 |

## D. 不适用与缺失处理

“不适用”必须给出理由，例如无商誉、无并购对赌、无出口、无有息债务。不能用“不适用”回避难查数据。缺失项必须列已核查来源、截止日和对估值/判断的影响；重大缺失应降低置信度或扩大估值区间。
