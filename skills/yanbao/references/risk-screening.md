## 1. 执行方式

逐项标记 `绿/黄/红/不适用/缺数据`。绿灯不等于无风险；红灯必须有原始事实与一手来源。任何自动提取结果都只能作为线索，必须回到转换后的年报/公告 Markdown 核对附注与上下文。

对每个红黄灯按六步写：事实 → 计算/同行或阈值 → 可能机制 → 反证/合理解释 → 判断与置信度 → 后续验证指标。

## 2. 十二类核查

### 2.1 多年趋势

- 资产负债率、有息负债、现金短债比、利息保障倍数连续3-5年。
- 商誉/净资产趋势、减值连续未计提年数；突然上升追溯并购。
- ROE/ROIC、净利率、资产周转、FCF和资本开支趋势。
- 研发资本化比例、审计机构/签字会计师和关键审计事项趋势。

### 2.2 行业横向对比

与可比公司中位数比较负债率、毛/净利率、ROE/ROIC、应收/存货周转、研发率与资本化、商誉/净资产、预付/总资产、资本开支强度。显著偏离必须解释商业模式差异。

### 2.3 附注、供应商、并购与商誉

- 前五供应商占比、关联方、成立时间/资本/处罚等异常；公开信息不足时披露穿透限制。
- 近3年关联并购：标的质量、估值公允性、交易前后利益输送迹象。
- 对赌：承诺与实际、精准达标、对赌期并购注水、期后变脸。
- 商誉减值：增长率、毛利率、折现率、评估机构独立性；未达标却不减值为强风险信号。

### 2.4 实控人、股东与高管

近3年减持金额和时点、高分红叠加减持、集体减持、业绩窗口前精准减持；高管尤其财务总监频繁离职；实控人/大股东立案、留置、处罚为重大红灯。检查质押率、解禁压力、资金占用和违规担保。

### 2.5 审计与诚信

- 审计意见必须为标准无保留才记绿；其他类型解释保留/强调事项。
- 审计机构质量、处罚、3年内换所、审计费异常下降、连续审计任期。
- 非审计费占比、关键审计事项数量及其是否对应公司重大风险。
- 证监会立案、行政处罚、失信、内控缺陷、重大诉讼、问询函。

### 2.6 研发资本化

`研发投入总额 = 费用化研发 + 内部研发资本化增加`；计算研发强度、资本化比例、调整后净利润，跨3-5年并与同行比较。业绩下滑期突然资本化、比例陡升或边界模糊为红黄灯。

### 2.7 固定资产与在建工程

- 项目供应商与采购价公允性；注册资本/人员与订单额严重不匹配。
- 对照公告投产时间查延迟转固：超计划2年黄、3年红；已投产仍长期在建为红。
- 闲置、低利用率、技术淘汰却未减值；转固后折旧和毛利率变化。
- 利息资本化率、资本化金额与工期；在建激增但投资现金无对应流出。
- 根据行业检查设备/技术淘汰、政绩工程和产能过剩。

### 2.8 交易性金融资产与公允价值

穿透股票、债券、基金、非上市股权和衍生品；检查关联方资产、估值模型、关键参数、评估独立性和敏感性。`投资收益+公允价值变动` 占营业利润超过30%黄、50%红；Q4集中确认、利润高但投资现金持续净流出需警惕。区分经营套保和方向性投机。

### 2.9 长期股权投资

被投企业利润与行业背离、Q4集中投资收益、关联交易贡献、估值异常；连续3年未减值黄、5年红；某年突然大额减值检查“洗澡”。检查49%/19%等临界持股、未并表企业高管控制、盈利高但现金弱、期末突击处置亏损资产。

### 2.10 负债、流动性与表外风险

- 短借激增但现金未增、借款用途/利率/抵押、短债长投。
- 应付与预付联动、账龄；合同负债不结转或突然下降；一年内到期负债激增。
- 其他应收/应付双高及关联方明细；长债利率、抵押、评级和交叉违约。
- 或有负债或诉讼/净资产超过10%黄、30%红；受限资金/货币资金超过50%黄、80%红。
- EBITDA利息保障 >3通常安全，1-3有压力，<1高风险；仍需结合行业波动。

### 2.11 前瞻性财报信号

- 购买商品现金、原材料、在产品、产成品、预付款与收入的联动；同一现象必须按行业解释。
- 原料增而收入未起可能是量产备料，也可能是滞销；产成品降且收入增更支持供不应求。
- 毛利率快速抬升偏周期，长期稳态并能修复偏结构；全线与局部涨价区别。
- 毛利率涨幅收窄、存货天数上升、营收环比减速是周期降温先行信号。
- 查管理层讨论、业绩指引、投资者关系活动记录，并评价回答质量。

### 2.12 市场信号

大股东精准减持、融资融券突变、龙虎榜异常、近期解禁占流通市值、实时质押率、研报覆盖骤降和评级集中下调。市场信号只作辅助，不能替代基本面证据。

## 3. 阈值与解释纪律

阈值是筛查器，不是结论。除上述阈值外，至少使用以下提示：

| 指标 | 提示线 |
|---|---|
| 流动比率 | <1.5关注，<1偏低 |
| 速动比率 | <0.8关注，<0.5偏低 |
| 现金比率 | <0.2关注，<0.1偏低 |
| 大股东质押率 | >70%重点关注平仓与资金占用 |
| 非审计费/审计费 | >15%黄，>30%红 |
| 审计任期 | >7年黄，>10年红 |
| 关键审计事项 | >5项黄，但结合公司复杂度 |
| 经营现金流/归母净利 | <0.8关注，<0.5红；负利润年份另行解释 |
| 应收/存货增速 | 高于营收且差距扩大需解释 |
| 现金短债比 | <0.5偏低，<0.3黄，<0.2红；剔除受限资金 |

不得把单季度季节性数据套全年阈值。Altman Z、粗略ROE和用财务费用代替利息的保障倍数必须标注近似，不得据此作确定性破产判断。

## 4. 输出格式

先给总表：

| 类别 | 状态 | 核心事实 | 阈值/同行 | 结论与跟踪 |
|---|---|---|---|---|

再给多年关键比率表、审计信息表，并重点展开红黄灯。不适用项要列理由；缺数据项要列已查来源。最后给综合风险评级（低/中/中高/高）、评级依据、最可能被市场忽略的风险和最可能被误判的“假风险”。
