# 研报完备性与质量门槛

在交付前逐项检查。任何失败项都应修复；无法修复的重大限制必须在摘要和口径说明中披露。

## 1. 结构覆盖

- [ ] 固定结构全部存在，适用项没有空标题、占位符或静默删除。
- [ ] 摘要覆盖行业、公司、排雷、估值、风险收益和失效条件。
- [ ] 行业含产业链、利润池、竞争、供需、成本定价、周期、政策技术、贸易ESG。
- [ ] 公司含发展阶段、控制链、业务、基地/产能、客户/定价、护城河、治理、股东和增长。
- [ ] 财务分利润表、资产负债表、现金流、归因/杜邦四节。
- [ ] 独立排雷章节含十二类判定、红黄绿汇总、关键比率和审计趋势。
- [ ] 估值含快照、历史分位、至少两方法、三情景、敏感性、压力测试和区间策略。
- [ ] 有风险表、催化剂时间轴、跟踪指标、关键数据核对区、口径来源和声明。

## 2. 最低表格/量化交付物

- [ ] 行业历史+预测供需表；周期/价格或修复驱动表。
- [ ] 分部收入/毛利表；产能/产量/产销表；在建项目表。
- [ ] 近5年+最新期核心财务、三表趋势、关键比率趋势、审计信息表。
- [ ] 同业竞争/财务/估值表；最近一期完整十大流通股东表。
- [ ] 未来3年分部预测；可核验机构预测汇总。
- [ ] 估值快照、可比/历史/其他方法结果、三情景、敏感性或压力测试。
- [ ] 操作区间、风险、催化剂、数据核对表。

## 3. 时间与口径

- [ ] 报告日、数据截止日和最新定期报告期明确。
- [ ] 当前价、估值、股东、公告、新闻、预测、行业价格都标具体日期。
- [ ] 年度、季度、TTM和预测分开；预测带E或明确标签。
- [ ] 股本、币种、合并/母公司、归母/扣非、设计/有效产能口径一致。
- [ ] 使用的年度确实是当时可获得数据，没有未来数据或历史任务日期残留。

## 4. 数字审计

- [ ] 所有逗号、万元/亿元、万股/亿股换算反向复核。
- [ ] 同一指标在摘要、正文、表格和估值中一致。
- [ ] 市值≈股价×股本；PE≈市值/净利；EPS≈净利/股本；目标价≈权益价值/股本。
- [ ] 供需、份额、产销率、利润率和同比公式可复算，百分比与百分点不混用。
- [ ] FCF、ROE、ROIC、利息保障等公式和近似限制已说明。
- [ ] 合计、分部抵销和少数股东没有重复计算。

## 5. 证据与来源

- [ ] 每个关键事实可回到事实台账；核心数字至少一项一手来源。
- [ ] 关键结论原则上两源交叉；单一来源和数据冲突已披露。
- [ ] 搜索摘要未被当作证据；来源写到具体公告/报告/页面和日期。
- [ ] 事实、第三方预测、自建模型和推断有明确标签。
- [ ] 无虚构数据、来源、券商观点、目标价或“行业均值”。

## 6. 分析一致性

- [ ] 行业供需 → 公司量价 → 分部利润 → 合并预测 → 估值形成完整链条。
- [ ] 护城河有证据和衰减条件；增长点有投产/爬坡/单位经济而非概念堆砌。
- [ ] 每个乐观判断有反证或失效条件；重大红灯进入摘要、风险和估值情景。
- [ ] 悲观情景真实改变经营假设，不只是降低估值倍数。
- [ ] 操作区间由估值反推；摘要结论不比正文证据更强。
- [ ] 已明确核心经营引擎和唯一关键变量，规模、技术、成本、客户等护城河有主次而非平铺标签。
- [ ] 管理层原话、已发生事实、管理层目标和研究者推断已分层，远期愿景未直接进入基准估值。
- [ ] 重资产公司已打通资本开支、在建、转固、折旧、爬坡、销量、利润和FCF，未把“投产”等同于“达产盈利”。
- [ ] 周期拐点同时使用季度同比与环比并排除季节和一次性因素；固定季度规律、宏观相关性和历史类比均经过验证而非当作定律。
- [ ] 新业务已检查技术、设备、客户、渠道和海外能力的可复用性，以及客户导入和批量收入阶段。

## 7. 表达与交付

- [ ] 每小节有明确“所以什么”，没有连续堆砌数据。
- [ ] 表格用于可比数据，正文用于机制与结论；没有长段落塞进单元格。
- [ ] “较高/较快/显著”等词有数字、区间或同行基准。
- [ ] 缺失项写明已查来源和影响，没有编造或无解释占位符。
- [ ] 文件保存于 `03_研究产物` 且命名、署名、日期和声明正确。

## 8. 自动覆盖审计建议

交付前用 `rg` 检查报告至少出现以下概念（同义标题可替代，但内容必须存在）：

```text
核心摘要|产业链|供需|成本|定价|价格周期|政策|贸易|ESG
利润表|资产负债表|现金流|自由现金流|量价|杜邦|排雷|审计
产能|产销|护城河|十大流通股东|未来三年|机构预测
历史分位|情景|敏感性|压力测试|操作策略|风险|催化剂|跟踪指标
关键数据核对|资料来源|重要声明
```

关键词检查只能发现疑似漏项，不能替代人工逐节核对。

完成关键词和人工核对后，运行：

```bash
python3 skills/yanbao/scripts/audit_report.py 03_研究产物/<报告文件>.md
```

只有用户明确要求简报时才可增加 `--brief`。脚本通过也不能替代本文件的口径、证据与分析一致性审计。
