## 1. 数据标准化

建立近5年加最新报告期的统一矩阵；资料允许时扩展至8-10年。保留原币种、原单位和原报表期，再统一为亿元/万元/元每股。年度、半年、季度和TTM分列，最新季度不得与全年直接比较。

先做：合并口径确认、追溯调整、会计政策变化、股本变化、非经常项目、少数股东损益和汇率换算。检查 `资产=负债+所有者权益`、利润表归母关系、现金及现金等价物变动与现金流表。

## 2. 利润表

至少分析：营业收入、营业成本、毛利、销售/管理/研发/财务费用、投资收益、公允价值变动、减值、营业利润、归母净利、扣非净利、EPS、分部收入和分部毛利率。补充ROA、ROIC，并在口径可得时计算有效税率和少数股东损益占比。

回答：

- 收入增长来自量、价、并表、汇率还是结构？
- 净利增速为何高于或低于收入？毛利率变化属于周期、结构、会计还是规模效应？
- 费用率的下降是真效率还是收入分母扩大？财务费用是否与借款/资本化利息一致？
- 归母与扣非的差异是否可持续？投资和公允价值收益是否主导利润？
- 分部结构是否出现低毛利业务扩张、高毛利业务萎缩？

用CAGR和分阶段叙事识别增长模式，至少列近5年核心业绩表。若出现“增收不增利”或“减收增利”，必须建立量价/成本/费用/结构解释。

## 3. 资产负债表

至少分析：货币资金、交易性金融资产、应收、预付、其他应收、存货三层、商誉、长期股权投资、固定资产、在建工程、短长借款、一年内到期负债、应付、合同负债、总资产、净资产和少数股东权益。

重点检查：

- 应收增速与营收、账龄与坏账率；存货原料/在制/产成品结构、周转与跌价。
- 货币资金与有息负债的存贷双高、受限资金、现金短债比和短债长投。
- 固定资产/在建工程增速、转固、折旧、产能利用率和资产周转率；估算未来转固折旧对利润的压制。
- 其他应收、预付、商誉、交易资产、长投的异常跳变及附注明细。
- 杠杆的方向、期限、利率、抵押和再融资压力，而不只看资产负债率单点。

## 4. 现金流量表

至少分析经营、投资、筹资净现金流、购建长期资产现金、分红、借款、偿还债务和现金净增加。

计算并解释：

- 净利含金量 = 经营现金流 / 归母净利润；近5年趋势及低于1的原因。
- FCF = 经营现金流 - 购建固定资产、无形资产和其他长期资产支付的现金。正文中明确这是简化FCF；必要时另算企业自由现金流。
- 资本开支强度 = 资本开支 / 营收；累计资本开支、累计FCF以及扩产阶段。
- 高分红是否由FCF覆盖；若FCF为负而持续分红/回购，说明资金来源。
- 筹资现金流是否反映借新还旧、股权融资或债务期限错配。
- 汇总近5年现金分红总额、分红率、股息率和重大再融资；用FCF覆盖率检验股东回报可持续性。

## 5. 业绩归因与杜邦

### 5.1 量价拆解

优先使用公司披露的销量与均价。若仅有收入和销量，以 `均价≈收入/销量` 做近似并注明混合产品误差。将收入变化至少拆为：销量、价格/汇率、产品结构、并表/其他。不能取得精确桥时给区间，并标为估计。

### 5.2 利润桥

从上期归母净利走到本期，分解：量、价、原料/能源、产品结构、费用、折旧、汇率、投资/公允价值、税率、少数股东和一次性项目。能量化则给亿元影响；不能量化则排序并写方向、证据和估计区间，禁止把定性判断伪装为精确数。

### 5.3 杜邦

`ROE = 归母净利率 × 总资产周转率 × 权益乘数`。尽可能用平均资产和平均归母权益，至少分析近5年。回答ROE变化由利润率、效率还是杠杆驱动，并用行业可比验证。

### 5.4 三表联动

至少检查：收入与应收/合同负债、成本与存货/应付/购买商品现金、固定资产/在建工程与资本开支/折旧、债务与利息/筹资现金流、净利与经营现金流、投资资产与投资收益。

## 6. 前瞻预测

预测未来3年，先分部后合并：

1. 产能 × 利用率 = 销量；销量 × 单价 = 收入。
2. 收入 × 毛利率，扣除费用、折旧、财务费用、税与少数股东得到归母净利。
3. 从经营现金流、资本开支和营运资金得到FCF。
4. 明确产能投产和爬坡、价格、成本、费用率、税率、股本的假设。
5. 与机构一致预期比较，解释差异，不可直接复制券商数字。

若公司类型不适合产能模型，改用用户/订单/门店/客户/份额等业务驱动，但必须保持“业务量 × 单位经济”的可复算关系。

## 7. 计算定义

| 指标 | 计算与注意事项 |
|---|---|
| 毛利率 | `(营收-成本)/营收`，与公司披露口径核对 |
| 净利率 | 归母净利/营收；另列公司净利润率时说明口径 |
| 应收占营收 | 年度用期末应收/营收；季度需注明未年化或使用TTM |
| 存货周转天数 | 平均存货/营业成本×365；季度按报告覆盖天数 |
| 现金转换周期 | DIO + DSO - DPO，三者尽量使用平均余额 |
| 资产负债率 | 总负债/总资产 |
| 有息负债率 | 有息债务/总资产或总资本，必须说明分母 |
| 现金短债比 | 可用现金/(短借+一年内到期有息负债)；剔除受限资金 |
| 利息保障倍数 | 优先EBIT/总利息；若用财务费用近似，明确限制 |
| EBITDA保障倍数 | EBITDA/含资本化利息的总利息支出 |
| ROIC | NOPAT/平均投入资本，说明税率和投入资本定义 |
| FCF | OCF-购建长期资产现金；若用其他定义另列 |
| Altman Z | 仅作辅助，说明上市制造业模型/账面值近似，不可单凭分数判破产 |

所有比率必须跨年看趋势、与同行中位数比较、结合行业解释，不能机械套阈值。

## 8. 重资产资本开支闭环与季度边际

对重资产公司追加执行 [core-engine-and-heavy-asset-method.md](core-engine-and-heavy-asset-method.md)。按项目和投产批次连接资本开支、在建工程、转固、折旧、产能、利用率、销量、吨均收入、吨均毛利、OCF与FCF；区分维持性、扩张性、效率型和战略期权资本开支。

至少建立8个季度的分部销量、吨均收入/价差、毛利率、核心经营利润、库存、资本开支、在建工程和有息负债序列。同时看同比与环比，排除季节性、检修、并表、库存收益和一次性项目后再判断“连续改善”。公告投产不得直接当作盈利兑现，必须继续验证商业运行、达产、客户认证和单位成本。

若使用自定义“核心利润”，逐项披露从法定利润到该指标的调整桥。若折旧增长快于销量，计算吨均折旧和达到盈亏平衡/目标毛利率所需的销量或利用率阈值。
