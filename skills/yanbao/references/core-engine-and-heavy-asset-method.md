## 1. 方法总纲：先抓关键矛盾

研究公司的目标不是收集最多信息，而是找出少数能解释其长期价值和当前变化的信息。开始写作前，强制回答：

1. **一句话核心经营引擎**：公司依靠什么稀缺能力，把什么投入转成客户愿意付费的产出？
2. **唯一关键变量**：若只能跟踪一个业务变量，应选什么？它为何比规模、收入增速或题材更接近利润本源？
3. **利润基础**：行业低谷时，公司靠什么仍能盈利或少亏？若低谷同样大亏，所谓护城河是否只是景气红利？
4. **当前关键矛盾**：是需求不足、价差收窄、折旧未摊薄、客户导入、原料切换、债务压力，还是估值已经先行？
5. **主次排序**：将业务和能力分成核心现金牛、配套业务、修复业务、第二增长曲线、远期期权。禁止把所有板块都称为“核心”。

输出一张“研究主线表”：

| 层级 | 项目 | 价值作用 | 当前状态 | 最关键证据 | 证伪条件 |
|---|---|---|---|---|---|
| 核心经营引擎 |  | 利润与估值基础 |  |  |  |
| 配套/协同业务 |  | 降本、保供或渠道 |  |  |  |
| 修复业务 |  | 周期或效率弹性 |  |  |  |
| 第二增长曲线 |  | 中期增量 |  |  |  |
| 远期期权 |  | 长期可能性 |  |  |  |

## 2. 核心经营引擎与护城河证伪

### 2.1 区分壁垒层级

不要把“规模大”直接等同于护城河。依次检验：

- **能不能做**：专利、配方、工艺诀窍、数据、牌照、认证、安全与环保门槛是否阻止进入？
- **能不能稳定做**：良率、连续运行、故障率、质量一致性和批量交付是否达到商业要求？
- **能不能低成本做**：原料路线、能耗、设备代际、装置规模、人工、物流和折旧是否形成成本曲线优势？
- **能不能卖出去**：客户认证、渠道、品牌、应用开发、售后和全球本地化是否构成商业化门槛？
- **能不能穿越低谷**：行业低谷时毛利、现金成本、开工率和现金流相对同行是否仍有优势？

将护城河拆成“必要条件”和“放大器”。独家工艺、牌照或客户认证可能是必要条件；规模只有在提高利用率、摊薄固定成本或加强议价权时才是放大器。若规模扩大却伴随价格战、低利用率或持续负回报，规模不是优势。

### 2.2 核心壁垒证据矩阵

| 候选壁垒 | 直接证据 | 经营结果证据 | 同行反证 | 复制所需时间/资本 | 衰减条件 | 结论 |
|---|---|---|---|---|---|---|

直接证据包括专利并不充分，还应查技术代际、生产线运行、客户验证和改造效果。经营结果证据至少包括低谷利润、单位成本、毛利率、开工率、份额或现金流。最后只选一个最核心壁垒，并解释其他优势如何依附或放大它。

### 2.3 利基与低谷测试

用完整周期而非景气高点判断利基：

- 公司低谷毛利率、营业利润率和FCF相对同行中位数；
- 行业亏损面扩大时，公司是否仍覆盖现金成本、折旧和利息；
- 低谷份额是否提升，是否存在被迫降价保开工或库存堆积；
- 优势来自结构性能力还是本国能源、人工、汇率等阶段性红利。

## 3. 公司历史、管理层与组织能力

### 3.1 用历史解释能力来源

公司沿革不能只列事件。对每个关键阶段回答：当时面临什么约束，管理层做了什么，付出什么代价，形成了什么可延续能力。重点查技术攻关、治理改制、逆周期投资、海外整合、重大失败和接班安排。

将“企业文化”“研发基因”“执行力”等软判断转换为可观察证据：研发组织方式、关键人才稳定性、失败容忍度、研发项目转量产率、资本配置回报、项目按期投产率、海外整合结果和低谷决策。

### 3.2 管理层信息四层分离

处理股东大会、电话会和投资者关系纪要时分成四层：

1. **管理层原话**：保留准确语境与日期。
2. **已发生事实**：可由公告、财报、环评、专利、产销或客户数据验证。
3. **管理层目标/愿景**：营收、份额、产能和长期定位，不当作盈利预测。
4. **研究者推断**：明确假设、推理链和待验证节点。

对容易歧义的“万亿、市占率、领先、投产、满产、订单饱满”等词核对对象、单位、时间和口径。管理层愿景既不能因过于宏大而直接否定，也不能直接进入估值；应拆成阶段里程碑并逐期验证。

## 4. 技术产业化与隐性基础设施壁垒

### 4.1 技术不能停在专利数量

对核心和新业务建立技术产业化阶梯：

`实验室定型 → 中试 → 客户送样 → 客户导入/认证 → 小批量 → 批量出货 → 多基地复制 → 技改降本`

逐项记录当前代际、主流代际、迭代周期、良率、客户认证数、批量收入、单位成本、下一代进度和淘汰风险。快速迭代、强定制行业尤其关注工艺研发、应用开发、客户协同和柔性组织，不能用传统大宗品的“有产能即可销售”逻辑。

评估技术改造时计算：改造资本投入、停工损失、能耗/原料/人工节省、产能增量、回收期，以及能否复制到其他基地。低资本技改带来的持续单位成本下降，可能比新建产能更有价值。

### 4.2 识别隐藏在厂区之外的壁垒

将供应链基础设施纳入护城河：矿源/原料权益、长期采购协议、船舶、港口水深和认证、码头、仓储、管道、铁路、保函、外汇能力、审批许可和海外运营经验。

采用“瓶颈清单法”：

| 环节 | 所需资源 | 公司现有能力 | 满产所需能力 | 缺口 | 建设周期/资本 | 竞争者复制难度 |
|---|---|---|---|---|---|---|

不只判断某项资源“有或没有”，还要测算数量是否足以支持规划产能，并预留检修、航线受阻、库存安全垫等冗余。长期合约本身也可能带来价格、履约和目的地限制，应同步评估风险。

## 5. 分部、法人、基地三层穿透

多业务、多基地公司不能只看合并报表。建立三张映射：

1. **分部视角**：产品、销量、收入、毛利、资本开支、折旧和经营重点。
2. **法人视角**：主要子公司/联营公司、持股、业务、收入利润、资产负债、现金流和关联交易。
3. **基地视角**：基地、装置、原料路线、产能、投产时间、利用率、物流和环保约束。

将三者勾连为 `法人—基地—产品—产能—收入—利润—资本开支—债务`。注意内部销售和合并抵销，不能把法人收入简单相加。法人穿透可用于发现哪个主体在赚钱、哪个主体承接债务、哪个项目仍在爬坡，以及海外业务的真实经营质量。

## 6. 重资产增长闭环

### 6.1 建立资本开支队列

按项目和投产批次追踪：

`资本开支 → 在建工程 → 转固 → 折旧 → 设计产能 → 爬坡 → 销量 → 吨均收入/价差 → 毛利 → OCF → FCF → 偿债/分红/再投资`

至少覆盖历史3-5年和未来3年。把资本开支分为：

- **维持性资本开支**：维持现有产能、安全、环保和设备更新；
- **扩张性资本开支**：新增产能、产品或基地；
- **效率型资本开支**：技改、节能、原料切换、自动化；
- **战略期权资本开支**：尚未完成市场验证的新业务。

无法从披露中直接分拆时，给估算区间和依据。总投资现金流不能直接等同于维持性资本开支，避免因此误判可持续FCF。

### 6.2 固定成本吸收与吨均经济

重资产新业务增收不增利时，至少拆成三类原因：产品/原料价差、产品结构、固定成本吸收。

计算：

- `吨均收入 = 分部收入 / 销量`
- `吨均毛利 = 分部毛利 / 销量`
- `吨均折旧 = 分部折旧 / 销量`
- `折旧费用率 = 分部折旧 / 分部收入`
- `固定资产周转率 = 分部收入 / 平均固定资产`
- `增量资本产出率 = 新增收入 / 累计扩张性资本开支`
- `增量资本回报近似 = 新增NOPAT / 累计扩张性投入资本`

估算达到盈亏平衡或目标毛利率所需的销量/利用率阈值。若产品多、渠道不共用，应逐产品或产品族分析客户导入速度，不能假设所有新增产能共享同一销售渠道。

### 6.3 区分“投产”和“兑现”

公告投产只代表物理完成，不代表达产、合格品率、客户认证、销量或盈利兑现。每个项目设置五个日期：机械完工、试车、商业运行、达产、盈利拐点。用产量、销量、产销率、单位成本和毛利率验证，不使用“项目已投产”直接推导利润。

### 6.4 资本开支、债务与股东回报

同时追踪经营现金流覆盖总资本开支、维持性资本开支覆盖、净债务、现金短债比和利息负担。区分有息负债与经营性无息负债，分析负债结构改善究竟来自偿债、现金增加、供应商信用还是口径变化。

当 `OCF > 总资本开支` 时才可称当期简化FCF转正；进一步判断是否能覆盖分红。若管理层称未来靠留存收益和折旧覆盖投资，应用未来资本开支队列、OCF和债务到期表验证。

## 7. 季度边际、周期与历史类比

### 7.1 年度趋势之外必须看连续季度

建立至少8个季度的序列：分部销量、吨均收入/价差、毛利率、核心经营利润、库存、资本开支、在建工程、有息负债和OCF。同比用于消除季节性，环比用于识别拐点；两者同时使用。

“连续改善”至少要求连续2-3个季度，并排除季节、一次性收益、原料库存收益、检修和并表影响。可构造“核心经营利润”，但必须逐项列出从报告利润剔除的项目，不得用自定义指标隐藏不利因素。

### 7.2 区分事件冲击与周期趋势

战争、事故、检修、政策和涨价函可能只是短期事件。建立：

`事件 → 供需/成本影响 → 持续时间 → 库存反应 → 价差变化 → 公司销量/利润 → 是否已被股价计入`

宏观指标与公司利润存在相关性时，检验领先/滞后期、历史样本、业务结构变化和反例，不能把相关性写成因果。所谓固定季度数的行业规律只能作为待检验假设，应回测多个周期，不能当成机械买卖时钟。

### 7.3 历史类比要同中求异

选取公司的上一轮相似阶段，至少比较：资本开支阶段、杠杆、产能利用率、价格/价差、宏观需求、竞争供给、业务结构和估值。列出相似点与不同点，说明哪些机制可能复现、哪些条件已经变化。

| 维度 | 历史阶段 | 当前阶段 | 是否可比 | 对结论的影响 |
|---|---|---|---|---|

## 8. 新业务与第二增长曲线

新业务不得只用市场空间和规划产能证明价值。依次验证：

1. 技术迁移是否真实：核心化学/工艺、设备、数据和人才有多少可复用？
2. 设备可转产性：共用设备比例、转产时间、改造资本和良率损失。
3. 客户和渠道可复用性：客户是否相同、认证是否重新开始、定制化程度。
4. 商业阶段：实验室、客户导入、批量、收入、盈利各到哪一步？
5. 全球化协同：海外建厂、工会、销售、法规和技术出口限制是否形成优势或约束？
6. 原料保障：自供、参股资源、长协与价格风险。

将管理层远期市场份额/营收愿景反推为所需产能、销量、客户数、资本开支和ROIC。若超出现有资源和行业容量，降低可信度；远期愿景只作为期权，不进入基准估值。

## 9. 估值阶段与预期差

把股价驱动拆成：

- **阶段一：估值修复**。风险消退或周期见底，PE/PB先从低位回升；盈利尚未明显兑现。
- **阶段二：盈利驱动**。销量、价差、利用率和利润持续改善；股价可上涨而PE下降。
- **阶段三：景气与预期共振**。盈利接近高位、估值也扩张；重点评估是否过度计价和退出条件。

用“当前股价隐含假设”反推市场已经计入的销量、价格、利润率和估值倍数，再与自建基准比较。估值方法的复杂度不能高于假设质量；若远期现金流不可靠，优先使用高/中/低利润区间、正常化盈利和资产负债表约束，同时保留多方法交叉验证。

周期公司明确“低谷利润、常态利润、景气利润”，不可把低谷PE或高峰PE机械横移。卖出或降仓条件应对应核心逻辑证伪、盈利/估值双高、供给扩张兑现或风险收益比恶化，而非仅看股价涨幅。

## 10. 持续验证和认知修正

研究结论必须可更新。建立“观察—验证—修正”表：

| 原判断 | 关键假设 | 下一验证数据/日期 | 实际结果 | 偏差原因 | 模型与结论修正 |
|---|---|---|---|---|---|

将变量分为：

- **必然/高确定性过程**：已完工项目折旧、合同债务到期、已签长期协议等；
- **高概率判断**：产能爬坡、成本下降、周期改善；
- **事件驱动**：事故、战争、检修、政策刺激；
- **愿景/期权**：远期份额、跨行业成功、未验证技术。

每次定期报告后更新分部数据、资本开支队列、项目兑现、债务、盈利区间和隐含预期。若事实与判断不符，先修正认知，不为原结论寻找借口。

## 11. 报告最低交付物

适用于重资产、多业务或技术制造公司时，报告至少增加：

- 一句话核心经营引擎、唯一关键变量、业务主次排序；
- 核心壁垒证据矩阵和低谷测试；
- 管理层原话/事实/目标/研究推断分层；
- 技术产业化阶梯和基础设施瓶颈清单；
- 分部—法人—基地映射；
- 资本开支队列及投产到盈利兑现表；
- 吨均收入、吨均毛利、吨均折旧和利用率阈值；
- 至少8季度边际经营序列；
- 历史相似阶段对照及差异；
- 估值修复/盈利驱动阶段判断和当前股价隐含假设；
- 观察—验证—修正表。

以上方法用于形成可证伪的研究框架，不代表任何特定公司事实或投资结论。
