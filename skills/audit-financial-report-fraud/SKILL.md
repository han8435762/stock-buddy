# 财报欺诈排查

把任务定位为“公开信息风险排查”，不要把异常直接写成欺诈事实。用财报内部勾稽、跨期变化、同行或外部事实组成证据链，并主动寻找反证。

## 1. 定位公司与资料

1. 当前目录为该公司的目录，例如：~/StockBuddy/companies/600573_惠泉啤酒，其中“600573_惠泉啤酒”就是“公司代码_公司名称”。
2. 读取根目录内的 `AGENTS.md`、`CLAUDE.md` 等项目规则（若存在）。
3. 运行 `python3 <skill-dir>/scripts/inventory_reports.py <company-root>` 生成候选资料清单。
4. 优先选择完整报告，避免用摘要替代已有的完整报告。年度排查尽量覆盖最近 3–5 个完整年度；最新季报或半年报要与上年同期、最近年末和同口径期间比较。
5. 季报通常是年初至报告期末的累计数。需要单季数据时，仅在合并范围与会计政策可比时计算：第二季度 = 半年报 − 一季报；第三季度 = 三季报 − 半年报；第四季度 = 年报 − 三季报，并明确标注“推算”。

## 2. 严格遵守信息优先级

按以下顺序取数，并记录每个数字来自哪一层：

1. `02_转换资料/` 中的完整年报、季报、半年报，以及审计报告、内控报告、资金占用、关联交易、会计差错更正、问询回复等本地 Markdown。
2. `a-stock-data` skill。查找当前环境可用的同名 skill。主要用其新浪三表补齐跨期数据，用巨潮公告核查遗漏公告，用 F10 或基本面接口辅助验证。不得用第二层覆盖本地原始披露而不解释差异。
3. WebSearch。仅用于前两层缺失、核查同行数据、监管处罚、审计机构/管理层变化、客户供应商真实性或行业价格趋势。使用当前环境可用的网页搜索 skill/工具，并给出链接、发布日期和访问日期。

若本地 Markdown 表格转换错位、数字缺列或单位不清，先在同一文件的附注/报表中交叉核对；仍无法确认时再回看 `01_原始资料/` 对应 PDF，并把该数字标记为“待核”。

## 3. 先建立基准事实表

逐期抽取并统一单位，保留原始数值：

- 利润表：营业收入、营业成本、毛利率、销售/管理/研发/财务费用、信用与资产减值、营业外及非经常性损益、净利润、扣非净利润。
- 资产负债表：货币资金、应收票据/账款/款项融资、其他应收款、预付款、存货、在建工程、固定资产、长期待摊费用、无形资产、商誉、应付账款/票据、合同负债、应付职工薪酬、有息负债。
- 现金流量表：经营现金流净额、销售收现、采购付现、其他经营现金、投资现金流及购建资产现金支出、筹资现金流和利息支出。
- 附注与治理：收入确认政策、坏账和存货跌价政策、账龄、受限资金、关联方、前五大客户/供应商、审计意见、关键审计事项、内控缺陷、会计估计/差错变更、审计师与财务负责人变动。

至少计算：

- 毛利率 = `(营业收入 − 营业成本) / 营业收入`
- 应收增速与收入增速差；存货增速与营业成本增速差
- 经营现金含金量 = `经营现金流净额 / 净利润`（净利润接近零或为负时不用该比率下结论）
- 销售收现率 = `销售商品、提供劳务收到的现金 / 营业收入`，注明其受增值税和合同负债影响
- 销售、管理、研发费用率及其跨期变化
- 有息负债、利息支出与平均借款成本的粗略匹配；高现金与高息借款是否并存

计算前统一单位，中间结果保留至少 4 位，最终通常保留 2 位；用原单位反向换算检查数量级。报告期、合并口径或会计政策不同，不得强行比较。

## 4. 沿证据链排查

完整读取 [references/fraud-red-flags.md](references/fraud-red-flags.md)，逐项检查其中与公司业务相关的信号。不要机械打勾；先理解商业模式、季节性、价格与原料周期，再判断异常是否违背业务逻辑。

对每个异常按以下链条验证：

1. **现象**：数字、趋势或披露发生了什么变化。
2. **可能手法**：收入虚增/提前确认、费用资本化、减值不足或洗大澡、现金流错分、关联方代垫、资金循环等。
3. **报表落点**：利润变化最终落在哪个资产、负债或现金流科目。
4. **原文核查**：查看会计政策、附注明细、账龄、交易对手、审计意见和管理层解释。
5. **交叉验证**：跨年度、同期、同行、公告或外部事实是否支持。
6. **反证**：列出能合理解释异常的因素及其证据；没有反证不等于证实欺诈。

优先追查“组合信号”，例如：

- 毛利率显著上升 + 应收增加 + 应付减少
- 存货周转恶化 + 毛利率反而上升
- 利润增长 + 经营现金流长期背离 + 应收/预付/在建工程上升
- 经营现金流异常好 + 投资现金流持续大额流出
- 现金充裕 + 高息借款或受限资金异常
- 大额减值/核销 + 管理层或控制权更替 + 次年业绩反弹

## 5. 证据分级与结论纪律

为每项发现标注证据等级：

- **A｜已证实事项**：监管处罚、司法/审计结论、公司正式差错更正或重述等直接证据。
- **B｜强风险信号**：至少两个相互印证的异常，能形成合理的资金或会计链条，且管理层解释不足。
- **C｜一般疑点**：单一异常、样本期太短或存在合理替代解释，需要继续核查。
- **D｜未见异常**：已检查的项目未发现重大异常；只能说明当前公开资料覆盖范围内未见，不得表述为“证明没有欺诈”。

总体风险只使用“高 / 中 / 低 / 信息不足”。除 A 级直接证据外，使用“疑点”“风险信号”“可能”措辞，不使用“造假公司”“已欺诈”等定罪式表达。

## 6. 输出报告

按以下顺序输出：

1. **结论摘要**：总体风险、最关键的 3 个依据、是否存在 A 级证据。
2. **资料覆盖**：已读报告、报告期、未取得或转换异常的资料、使用过的数据层级。
3. **核心指标跨期表**：原始值、单位、同比/环比或推算值、精确来源。
4. **风险发现矩阵**：`证据等级 | 现象 | 数据/原文 | 可能手法 | 反证/合理解释 | 判断 | 来源`。
5. **三表与附注详查**：收入、费用、现金流、资产负债表、关联方及治理信号。
6. **反证与不确定性**：主动说明哪些因素削弱欺诈假设。
7. **下一步核查清单**：具体到公告、科目、交易对手、同行或所需原始凭证。

引用本地资料时给出可点击的绝对路径，尽量附行号；引用网页时给出直达链接。结论必须能回溯到原始数字或原文，不得只输出风险分数。
